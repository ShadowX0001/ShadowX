# ShadowX

ShadowX is an independent launcher/client project built from the Starling codebase,
with Horizon upstream compatibility work. Original licenses and third-party notices
are retained in the source tree. See `LICENSE`, `NOTICE`, and third-party license files.

## Project status

The source bootstrap is in progress. A successful CI job is not a claim of complete
Android/Desktop support; platform builds and runtime tests are tracked separately.

## Development

- Rust workspace: Cargo workspace at the repository root.
- CI: GitHub Actions.
- Android: native Android target; requires Android SDK/NDK and device testing.
